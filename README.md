# Acxiom CRM

A Django-based Customer Relationship Management (CRM) system for managing customers, leads, opportunities, follow-ups, activities, users, and audit logs.

## Features

- User authentication and login
- Role-based access control
- Admin, Manager, and Sales Executive roles
- Customer management
- Lead management
- Opportunity management
- Follow-up management
- Activity tracking
- Audit log management
- Dashboard with CRM statistics
- REST API using Django REST Framework
- SQLite database
- Django Admin interface

## Technology Stack

- Python
- Django
- Django REST Framework
- SQLite
- HTML/CSS
- Git & GitHub
